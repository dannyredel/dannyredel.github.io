Widget preview

This is a mock page. The floating chat button in the bottom-right is the real chatbot/widget.html.

Note: Opening this file directly (file://) will render the widget UI but fetch() to localhost:8000 will be CORS-blocked. To actually talk to the backend, run python -m http.server 4000 from the Quarto repo root and visit http://localhost:4000/chatbot/preview.html.

Sample content

Scroll down to confirm the widget stays pinned to the bottom-right. Click the button to open the chat panel and try the starter chips. The mobile layout kicks in under 640px — resize the window to check.

When you're happy with the widget, run quarto preview from the repo root to see it embedded on every page of the real site via _quarto.yml → include-after-body.

What the widget is doing

  • POSTs {"question": "..."} to /api/chat
  • Reads a text/event-stream response and parses data: lines
  • Renders type: "token" events into the bot bubble as they arrive
  • Closes on type: "done"
